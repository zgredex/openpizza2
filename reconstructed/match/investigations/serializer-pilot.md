# VC6 serializer pilot

`tools/verify_serializer_pilot.py` generates scratch C++ from eight named exports using a shared stream and collaborator ABI. The generator checks the ordered direct calls and callee cleanup against the pinned PE before compiling. It keeps the source, object, and strict matcher receipt for each attempted function in the chosen scratch directory.

```sh
python tools/verify_serializer_pilot.py --out /tmp/pc2-serializer-pilot --verify --jobs 4
```

Use Capstone 5.0.7 and the [pinned VC6 SP3 toolchain](../VC6_TOOLCHAIN.md). The test fixes the flags at `/O2 /TP`. Omit `--verify` to validate the extraction and generate sources without Wine. Repeat `--address` to select up to eight named serializers.

The GamePlan, calendar, and character pairs test repeated fixed-field transfers. Calendar load adds a save-version gate. `IsoMap_Save` adds repeated records and compressed cells. `Branch_Save` adds record lookups and dependent serializers. Together they cover 5,166 candidate bytes. `report.json` gives the strict byte count and the earliest difference for any compiled miss. Only strict receipts contribute to the count.

## Measured result

Six of eight functions passed the strict verifier, for **1,325 code bytes**. The initial calendar load compiled the version fallback before the stream read. Rendering the equivalent signed guard with the read arm first matched the original's `cmp 45; jle fallback` and recovered the full 190-byte function. The other generated sources remained byte-identical.

## Typed adapters

The translator preserves a typed stream slot such as `int *`, a slot Ghidra reuses as `void *`, and narrow scalar or pointer types in the second stack slot. It makes byte offsets on `void *` globals explicit. All eight original pilot sources regenerated byte-for-byte after these changes.

`List_Add` at `0x4014b0` reads a dword argument and returns with `ret 4`. The original call at `0x47b5d6` independently confirms one push and the receiver in ECX. That adapter covers the list insertion in `Player_AIState_Load`. `Branch_Load` and `Company_Load` parse with their typed signatures and still require their allocation, constructor, and exception-handling shapes. Extraction reports the unmodeled direct callees by name and address.

A shared save rewrite removes the assignment Ghidra inferred from `push ecx` when the temporary is assigned again immediately before its sole write. It also uses the saved stream receiver for the first write. In the bounded compile, `Player_AIState_Save` dropped from 211 code-byte differences to two, both in the prologue's EDI/ECX moves. `Storage_SaveRecord` dropped from 178 to 113, starting at `+0x3`. `Player_AIState_Load` still first diverges at `+0x4` with 215 differences. These three add no strict bytes.

## Discover and verify stream callers

```sh
python tools/verify_serializer_batch.py --out /tmp/pc2-serializers
python tools/verify_serializer_batch.py --out /tmp/pc2-serializers-checked \
  --reuse /tmp/pc2-serializer-pilot --verify --jobs 4
```

Discovery scans indexed contiguous functions with a direct call to the
stream reader or writer and an available named export. It skips addresses
with tracked C/C++ drafts. Use `--address` to select candidates from this
inventory and repeat `--reuse` to check several previous object directories.
The verifier compares each reusable object against its source and compiler
fingerprints and reruns the strict matcher before linking a scratch PE.

Discovery found 38 functions and 30,525 candidate bytes, including the six
previous strict matches. Typed signatures and the `List_Add` binding reduced
signature blockers from 17 to 10 and raised the number of compile-ready
functions from 10 to 11. The expanded run finished with **6 strict, 5 byte
mismatches, and 27 unsupported**. All six reused objects independently
linked into a byte-identical scratch PE. Subsequent `/G5`, `/GX`, and
`/Ob1` trials for `Player_AIState_Save` stayed at two differences. `/G6`
increased the difference count to 99.
